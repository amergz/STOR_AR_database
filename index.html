Cara setup PERCUMA guna Google Sheet (5-10 minit):
1. Buka sheets.google.com → buat 1 Google Sheet baru (kosong pun boleh)
2. Menu Extensions → Apps Script
3. Padam semua kod sedia ada, tampal kod Apps Script yang admin bagi (rujuk arahan penuh)
4. Tekan 💾 Save, kemudian Deploy → New deployment
5. Pilih jenis "Web app" → Execute as: Me → Who has access: Anyone → Deploy
6. Benarkan kebenaran (Authorize access) bila diminta
7. Copy URL Web app (berakhir dengan /exec) → tampal kat bawah ni → tekan Sambung
