☁️ Setup Cloud Sync

Cara dapatkan config PERCUMA (5 minit, guna akaun Google):
1. Pergi ke console.firebase.google.com
2. Tekan "Add project" → beri nama apa-apa → ikut langkah lalai → Create
3. Dalam project, tekan ikon </> (Web) untuk daftar app baru → beri nama → Register
4. Firebase akan tunjuk kod firebaseConfig = {...} — copy SEMUA block tu
5. Tampal kat bawah ni, tekan Sambung
6. Pergi menu "Firestore Database" di Firebase → Create Database → pilih mode "Test mode" → Enable
